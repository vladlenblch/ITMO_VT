## 📋 Описание проекта

REST API на Spring Boot обрабатывает регистрацию/логин и проверку попадания точек в составную область, хранит пользователей и результаты в PostgreSQL. React-клиент с Redux Toolkit и React Router позволяет отправлять точки кликом по графику или через форму.
