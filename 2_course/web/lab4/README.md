# 🎯 Лабораторная работа №4

## Основная лабораторная работа
Spring Boot + React + Redux + PostgreSQL + REST API: веб-приложение с авторизацией и проверкой попадания точки в заранее заданную область с помощью формы или кликом по графику. Веб-приложение включает 2 страницы: начальная страница авторизации и страница отправки формы.

## Дополнительное задание
Вместо хранения логина и хеша в одной таблице реализовать трехкомпонентную модель: Principal - абстрактный идентификатор (user_id, UUID), Credential - способ подтверждения (пароль, TOTP, recovery code), Evidence - доказательство владения (например, HMAC(challenge, secret)). Позволить пользователю иметь несколько независимых учетных данных (например, пароль + 3 резервных кода). Удаление одного способа не блокирует вход. Вся логика через CDI-бин-стратегии (+ добавить валидацию через Zod).
