# 🎯 Лабораторная работа №3

## Основная лабораторная работа
Веб-приложение на Java с вводом координат через форму, либо нажатием на график. Проверяет попадание точки в заданную геометрическую область с визуализацией на графике. Веб-приложение включает 2 страницы: начальная страница с интерактивными часами и страница формы ввода.

## Дополнительное задание
Построить самоприспосабливающуюся систему с обучением с подкреплением. Система сама подстраивает параметры: если пользователь часто ошибается - временно увеличивает радиус для обучения, если нагрузка высока, переключается на приближенную проверку. Обучение происходит через онлайн-агент обучения.
